Appendix B — Statistical Analysis Plan (mock): clinical performance study SIM-217-001

Two-cut-off plasma pTau217-like test vs amyloid PET. Simulated data only.

Status of this document. A teaching SAP. The study, device, data and numbers are simulated; the structure follows ICH E9 by analogy and the content items of IVDR Annex XIII Part A 2.3.2 (statistical design, endpoints, population size, method for determining true clinical status). No claim is made that a regulator accepts this plan. Tags: [S] public source, [A] assumption, [Y] my synthesis.

1. Objectives and hypotheses

Intended use (simulated). Aid in identifying amyloid pathology in adults aged 55 years and older with signs, symptoms or complaints of cognitive decline; used with other clinical information; not stand-alone; not for monitoring. [A]

Primary objective. Show that a positive result carries a high probability of amyloid-PET positivity and a negative result a low one.

Co-primary endpoint Performance goal (H0) Expected value Success rule
P1: PPV of the positive category PPV ≤ 0.75 0.88 [A] lower limit of two-sided 95% Wilson CI > 0.75
P2: NPV of the negative category NPV ≤ 0.90 0.95 [A] lower limit of two-sided 95% Wilson CI > 0.90

Success requires both (intersection-union): no alpha adjustment is needed because each test is run at the one-sided 0.025 level and both must reject. [Y]

Secondary objectives. Intermediate-zone fraction; PPA and NPA with intermediates counted as non-agreement; PPV/NPV of each category with likelihood ratios; performance by pre-specified subgroups.

2. Design, reference standard and cut-offs

  • Design. Prospective-retrospective, banked K2-EDTA plasma, multi-site, primary and secondary care. [A]
  • Reference standard. Amyloid PET visual read by a blinded reader panel (≥ 3 readers, majority rule; unreadable scan = missing). The interval between blood draw and PET is recorded; per-protocol requires ≤ 180 days. Readers are blind to the index test; index-test operators are blind to PET. [A]
  • Cut-offs (locked). Derived on a separate simulated derivation cohort (n = 700) by derive_two_cutoffs() with targets sensitivity ≥ 94% (rule-out) and specificity ≥ 93% (rule-in); stored in data/locked_cutoffs.csv and not re-estimated on performance-study data. Convention as in the public decision summary [S]: negative if ≤ lower cut-off, positive if > upper cut-off.

3. Analysis populations

Population Definition Role

Per-protocol evaluable, PET interval ≤ 180 days, no major deviation sensitivity analysis

4. Endpoints and statistical methods

  • Proportions: Wilson 95% CIs (primary); Clopper–Pearson as sensitivity. PPV = positive-category subjects with PET+ / all positive-category subjects; NPV analogously. Both are conditional on category and prevalence-dependent; observed prevalence reported with CI.
  • Likelihood ratios per category with log-scale 95% CI (asymptotic, ratio of two proportions).
  • PPA = (positive result among PET+); NPA = (negative result among PET−); intermediates count as non-agreement (as in the public decision summary [S]). Rule-out step sensitivity and rule-in step specificity as additional descriptors.
  • No imputation of PET. Subgroup CIs are descriptive; interaction tests are exploratory and not used for claims.

5. Sample size

Planning assumptions [A]: positive-category frequency 0.336 and negative-category frequency 0.465, taken from the public pivotal data of a comparable cleared test (FDA K261686, p.27 [S]) and used here only as planning inputs; 8% loss to non-evaluable.

n_pos <- n_exact_goal_stable(0.88, 0.75, alpha = 0.025, power = 0.90)   # subjects with a positive result
n_neg <- n_exact_goal_stable(0.95, 0.90, alpha = 0.025, power = 0.90)   # subjects with a negative result
N_pos <- ceiling(n_pos / 0.336); N_neg <- ceiling(n_neg / 0.465)

Joint power of the two co-primaries is approximately the product of the individual powers when the two are nearly independent (≈ 0.81 for 0.90 each) [Y]; the planned N exceeds the requirement, which raises it. Cross-check method: the exact calculation matches MKmisc::power.diagnostic.test (Day 7, tested).

6. Missing, invalid and unreadable results

  • Invalid assay results are repeated once per the instructions for use (not simulated); results still invalid are excluded from the evaluable set and reported in the flow table.
  • Unreadable PET = missing reference; excluded from evaluable. Sensitivity analysis S2 (worst case): invalid assay results among PET+ are counted as negative, among PET− as positive.
  • A STARD flow diagram (Table 1) documents all exclusions. [S: STARD 2015 has 30 items]

7. Subgroups (descriptive)

Age (55–70, 71–85), sex, care setting (primary, secondary), MMSE (15–24, 25–27, 28–30), kidney function by eGFR (< 30, 30–59, ≥ 60), with a minimum of 20 subjects per category for a CI to be reported. Kidney function is pre-specified because the public decision summary of the comparable test contains no eGFR-stratified analysis (only a small kidney-disease comorbidity subgroup) [S].

8. Multiplicity, interim analyses, sensitivity analyses

  • Co-primary success rule above; secondary and subgroup results are not adjusted and are labelled descriptive. No interim analysis (fixed sample).
  • S1 per-protocol; S2 worst-case for invalid assay results; S3 Clopper–Pearson intervals.

9. Data standards

CDISC publishes SDTMIG for Medical Devices (v1.1, 2019) and ADaMIG for Medical Devices (v1.0, 2021) [S: cdisc.org]; no IVD-specific CDISC standard was found, and nothing verified says CDISC is required for IVDR submissions. This mock uses ADaM-style analysis datasets (subject-level ADSL, performance ADPERF) by analogy, with variable names and derivation notes in the programming specification. [Y]

lr <- function(cat) {
  n1 <- sum(ev$PET_VISUAL == 1); n0 <- sum(ev$PET_VISUAL == 0)
  a <- sum(ev$CAT == cat & ev$PET_VISUAL == 1); b0 <- sum(ev$CAT == cat & ev$PET_VISUAL == 0)
  p1 <- a / n1; p0 <- b0 / n0; est <- p1 / p0
  se <- sqrt((1 - p1) / (n1 * p1) + (1 - p0) / (n0 * p0))
  sprintf("%.2f (%.2f-%.2f)", est, exp(log(est) - 1.96 * se), exp(log(est) + 1.96 * se))
}

12. Double programming: independent QC comparison

A second programmer re-derives the primary endpoints from the raw CSV without using the project helpers (different packages, different code path); the lead programmer’s results must agree.

raw <- read.csv("data/sim_ptau217.csv"); raw <- raw[!is.na(raw$PTAU217) & !is.na(raw$PET_VISUAL), ]
neg <- raw$PTAU217 <= LO; pos <- raw$PTAU217 > HI
w_ppv <- binom.confint(sum(pos & raw$PET_VISUAL == 1), sum(pos), methods = "wilson")
w_npv <- binom.confint(sum(neg & raw$PET_VISUAL == 0), sum(neg), methods = "wilson")
qc <- data.frame(item = c("PPV est", "PPV lower", "NPV est", "NPV lower"),
