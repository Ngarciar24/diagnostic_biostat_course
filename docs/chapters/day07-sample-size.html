Day 7. Sample size and power for diagnostic studies

Tags: [S] primary public source, [Y] my synthesis, [A] assumption. Every number below is computed two ways (package vs hand, or hand vs simulation).

(a) Concept

Goal Quantity to fix Typical output
Estimate Se or Sp precisely CI half-width d, expected Se/Sp, prevalence n cases, then total n = cases / prevalence
Show Se (or Sp) exceeds a performance goal goal p0, expected p1, α, power n cases (exact binomial)
Show AUC > AUC0 or estimate AUC precisely expected AUC, null, group ratio n cases and controls
PPA/NPA vs a comparator as Se/Sp but denominators are comparator-positive/negative total n via comparator prevalence
Precision studies days, runs, replicates degrees of freedom → CI width
LoB/LoD number of blanks and low samples precision of the percentile / SD

Total n is driven by the rarest class: for sensitivity you need cases, and cases arrive at the rate of the prevalence. [Y]

3. Show sensitivity beats a performance goal (exact test)

Expected Se p1 = 0.90, goal p0 = 0.80, one-sided α = 0.025 (matches a two-sided 95% CI), power 80%.

n_hand <- n_exact_goal_stable(0.90, 0.80, alpha = 0.025, power = 0.80)
n_mk   <- power.diagnostic.test(sens = 0.9, delta = 0.1, power = 0.8, sig.level = 0.025, prev = 0.2)$n
# simulation: power at n_hand with exact one-sided binom.test
set.seed(72)
pw <- mean(replicate(4000, binom.test(rbinom(1, n_hand, .9), n_hand, p = .8, alternative = "greater")$p.value < .025))

4. AUC

Expected AUC 0.90; test against AUC0 = 0.75, two-sided α = 0.05, 80% power, 1:1 cases:controls.

n_h <- n_auc_hm(0.90, 0.75, alpha = 0.05, power = 0.80)
# simulation with the binormal model: AUC = pnorm(delta/sqrt(2)) for equal unit variances
delta <- function(a) sqrt(2) * qnorm(a)
set.seed(73)
sim_power <- function(n, a1 = 0.90, a0 = 0.75, reps = 600) {
  mean(replicate(reps, {
    cs <- rnorm(n, delta(a1)); ct <- rnorm(n)
    r <- roc(rep(1:0, each = n), c(cs, ct), quiet = TRUE, direction = "<")
    ci <- ci.auc(r, method = "delong")            # reject if the lower 95% limit exceeds AUC0
    (as.numeric(ci)[1] > a0)
  }))
}
grid <- c(20, 24, 28, n_h)
kable(data.frame(`Cases = controls` = grid, `Simulated power` = sapply(grid, sim_power),
                 check.names = FALSE),
      caption = sprintf("Hanley-McNeil n = %d per group; power by simulation (600 reps)", n_h))
Hanley-McNeil n = 34 per group; power by simulation (600 reps)
Cases = controls Simulated power
20 0.7800000
24 0.8550000
28 0.8766667
34 0.9266667

The Hanley–McNeil formula is conservative here: the simulated power at its n is well above 80%, and 80% is reached with fewer subjects. The simulated rule (DeLong lower 95% limit > AUC0) is a one-sided α = 0.025 test, which is the same critical value as the two-sided 0.05 used in the formula, so the gap comes from the variance approximation, not the α. Use the formula to plan, simulation to confirm. [Y]

5. PPA/NPA and the indeterminate fraction

When intermediates count as non-agreement, the quantity to size is PPA_incl = Se_det·(1 − f_D) where f_D is the intermediate fraction among comparator-positives.

6. Design sizes for EP05 and EP17-type studies (illustrative)

Precision, CI width of within-lab SD versus number of days. Satterthwaite df of the sum of mean squares; hand check against VCA’s DF for the Day 2 data.

sat_df <- function(ms, D, R, K) {
  cf <- c(day = 1 / (R * K), run = (R - 1) / (R * K), err = (K - 1) / K)
  df <- c(D - 1, D * (R - 1), D * R * (K - 1))
  sum(cf * ms)^2 / sum((cf * ms)^2 / df)
}
# MS from the Day 2 simulated study (VCA output): day 9.906929, run 5.628042, error 4.808839
df_hand <- sat_df(c(9.906929, 5.628042, 4.808839), 20, 2, 2)

ci_ratio <- function(D, R = 2, K = 2, sd_d = 1.2, sd_r = 1.5, sd_e = 2) {
  ms <- c(sd_e^2 + K * sd_r^2 + R * K * sd_d^2, sd_e^2 + K * sd_r^2, sd_e^2)
  df <- sat_df(ms, D, R, K)
  c(days = D, df = df, `upper/estimate` = sqrt(df / qchisq(.025, df)), `lower/estimate` = sqrt(df / qchisq(.975, df)))
}

LoB: precision of the 95th percentile vs number of blanks.

set.seed(74)
sim_lob <- function(n, B = 4000) {
  p <- replicate(B, { b <- rnorm(n); c(np = unname(quantile(b, .95, type = 6)), par = mean(b) + 1.645 * sd(b)) })
  data.frame(blanks = n, `SD nonparametric` = sd(p["np", ]), `SD parametric` = sd(p["par", ]),
             `theory SD parametric` = sqrt(1 / n + 1.645^2 / (2 * (n - 1))), check.names = FALSE)
}

(d) Ten interview questions

show_questions(7, "../interview_questions.csv")

Q1. How many subjects do you need to estimate sensitivity to +-5% when you expect 90% and prevalence is 20%?

Cases: n = z^2 p(1-p)/d^2 = 1.96^2*0.09/0.0025 = 138 (Wald); Wilson-based presize gives 141. Total = cases / prevalence = about 692-705. The prevalence turns 140 cases into about 700 subjects.

Q2. Why does prevalence inflate sample size for sensitivity but not for specificity?

Sensitivity uses only cases, specificity only non-cases. Total n = n_cases/prev for sensitivity and n_controls/(1-prev) for specificity. At low prevalence cases are scarce. Fix: enriched sampling, with PPV/NPV reweighted to the true prevalence.

Q3. <98><85> How do you size a study to show sensitivity exceeds an 80% performance goal?

Choose the expected true sensitivity (say 90%), one-sided alpha (0.025), power (80%); use the exact binomial test: about 94-113 cases depending on alpha (0.05 -> 94, 0.025 -> 113 in my calculation). Check by simulation and note the sawtooth in exact power.

Q4. Why is exact power not monotone in n?

The binomial is discrete: the critical count jumps by integers while power varies smoothly, so power can fall when n increases by one. Report the smallest n beyond which power stays above target.

Q5. How do you choose the expected sensitivity to size the study?

From prior studies or pilot data, shaded conservatively (use the lower end of a prior CI), and show a sensitivity table over a range. Over-optimism leads to underpowered studies; the goal itself comes from clinical need or comparators.

Q6. <98><85> How do you size a study for AUC?

Specify expected AUC, AUC0 (null or goal), alpha, power, case:control ratio, then use Hanley-McNeil (or DeLong-based) variances. Cross-check with pROC::power.roc.test (versus 0.5) and presize::prec_auc (CI width) and simulation.

Q7. <98><85> How does a 20% indeterminate fraction change the plan?

If intermediates count as misses, expected PPA falls (94% determinate sensitivity x 0.8 = 75%), so the goal must be set on that scale; if you need a number of determinate cases, inflate n by 1/(1-f). Pre-specify which endpoint is primary.

Q8. Why does a precision study need many days?

Df for the day component is days-1; within-lab SD CI is driven by that df. 20 days with 2x2 per day gives about 70 Satterthwaite df and an expected 95% CI of about 0.85-1.22 times the estimate in my example (0.80-1.35 with 10 days).

Q9. How many blanks for LoB?

EP17 gives numbers (not verified, paywalled). Statistically, the parametric LoB SD is about sqrt(1/n + 1.645^2/(2(n-1))) x SD_blank; the nonparametric 95th percentile is noisier, so n of 60 or more is a reasonable starting point for a nonparametric claim.

Q10. Name sources for diagnostic sample size and say what each gives.

Buderer 1996 (Se/Sp with prevalence), Flahault et al. 2005 (case tables for an acceptable lower limit), Hanley and McNeil 1982 (AUC SE), Obuchowski (ROC sample size tables, AJR 2000 / Invest Radiol 1994), Zhou, Obuchowski and McClish (textbook). Tools: presize, MKmisc, pROC.
