Day 2. Precision and variance components (EP05, EP15)

Tags: [S] primary public source, [Y] my synthesis (standard theory, not quoted).

(a) Concept

  • Repeatability = within-run noise. Between-run, between-day add drift. Within-laboratory precision = all three together (one site, one instrument).
  • Variances add; SDs do not. SD_within-lab = sqrt(σ²_day + σ²_run + σ²_rep). [Y]
  • CV% = 100·SD/mean at a given level. Always report at medical decision levels.

(c) R lab: simulate and analyse an EP05-style study

True values: day SD 1.2, run SD 1.5, repeatability SD 2.0 at a mean of 100.

set.seed(20)
D <- 20; R <- 2; K <- 2
d <- expand.grid(rep = 1:K, run = 1:R, day = 1:D)
d$y <- 100 + rnorm(D, 0, 1.2)[d$day] +
  rnorm(D * R, 0, 1.5)[(d$day - 1) * R + d$run] + rnorm(nrow(d), 0, 2)
d$day <- factor(d$day); d$run <- factor(d$run)

Three estimators, one answer (cross-check required by rule 4)

The standard precision table

Verification against a claim (EP15 logic, [Y])

# Pretend a manufacturer claims repeatability SD = 2.0; we ran 5 days x 5 replicates (df = 20)
s_obs <- 2.3; nu <- 20; claim <- 2.0
uvl <- claim * sqrt(qchisq(0.95, nu) / nu)
data.frame(claim, observed = s_obs, df = nu, UVL = round(uvl, 3),
           verified = s_obs <= uvl)

Bayesian version (brms)

Weakly informative half-normal priors on all SDs; fitted once and cached in cache/.

cache <- "../cache/ep05_brms_draws.rds"           # posterior draws only (a few KB); delete to refit (about 2 min)
if (file.exists(cache)) {
  dr <- readRDS(cache)
} else {
  b <- brm(y ~ 1 + (1 | day) + (1 | day:run), d, chains = 2, iter = 2000, cores = 2,
           prior = c(prior(normal(100, 20), class = Intercept),
                     prior(normal(0, 3), class = sd),
                     prior(normal(0, 3), class = sigma)),
           backend = "rstan", seed = 1, refresh = 0, silent = 2)
  dr <- as.data.frame(as_draws_df(b))[, c("b_Intercept", "sd_day__Intercept", "sd_day:run__Intercept", "sigma")]
  saveRDS(dr, cache)
}
sd_draws <- cbind(day = dr$sd_day__Intercept, run = dr$`sd_day:run__Intercept`,
                  rep = dr$sigma)
wl <- sqrt(rowSums(sd_draws^2))
q <- function(x) sprintf("%.2f (%.2f - %.2f)", median(x), quantile(x, .025), quantile(x, .975))
kable(data.frame(

                                  q(sd_draws[, "rep"]), q(wl)),

(d) Ten interview questions

show_questions(2, "../interview_questions.csv")

Q1. Describe the single-site EP05-A3 precision design and what it estimates.

20 operating days x 2 runs/day x 2 replicates per sample (EP05-A3, 2014 [S: CLSI press release]). A nested (day > run > replicate) random-effects model gives repeatability (within-run), between-run, between-day and within-laboratory (total single-site) imprecision. Note EP05 is now Ed4 (Dec 2025); I know the Ed4 design only as ‘not verified: paywalled’.

Q2. How is within-laboratory precision computed from the components?

Add the variances, not the SDs - within-lab SD = sqrt(var_day + var_run + var_repeatability). CV% = 100 x SD / grand mean at that level. Components estimated by ANOVA (method of moments) or REML; identical for balanced data.

Q3. Why can a variance-component estimate be negative, and what do you report?

In ANOVA, (MS_between - MS_within)/k can be < 0 by sampling noise when the true component is near 0. Report it as 0 (truncate) for the total, state that, and note CI lower limits are constrained at 0. REML/Bayesian estimators cannot go below 0 by construction.

Q4. <98><85> How do you get a CI for a variance component or for the within-lab SD?

Chi-square intervals with Satterthwaite-approximated degrees of freedom for the sum of mean squares (what VCA::VCAinference does in its ‘SAS’ mode). The effective df of within-lab SD is ~70 for 20x2x2 - lower than the 80 observations suggest, because day carries only 19 df.

Q5. How does user verification (EP15) differ from the manufacturer’s EP05 study?

EP05 establishes imprecision claims (manufacturer, large). EP15 is a short lab-level study (public page: completed within five working days; bias needs >= 25 measurements over >= 5 days) that checks whether the lab’s imprecision is consistent with the claim, using an upper verification limit from a chi-square argument [S: clsi.org EP15 page; the UVL formula is my synthesis, text not reproduced].

Q6. <98><85> Show the upper verification limit logic for a claimed repeatability SD.

If observed SD s has df = nu, then s^2nu/sigma_claim^2 ~ chi2(nu). Verification passes if s <= sigma_claim sqrt(chi2_{0.95,nu}/nu) (one-sided 5% test of H0: sigma = claim). Larger nu -> UVL closer to the claim. Synthesis of standard theory.

Q7. Why 20 days instead of, say, 5 runs on one day?

Day-to-day (calibration, reagent, environment) variance is typically the biggest source of lab imprecision and is only estimable from many independent days; replicates inside a day tell you almost nothing about it. Df for day drives the CI width of within-lab SD.

Q8. <98><85> Where does your Bayesian hierarchical variance model map onto EP05, and where does it differ?

Same model structure: day and run random effects around a mean, residual = repeatability. Differences: priors on SDs (shrinkage with few levels, never exactly zero), credible not confidence intervals, no closed-form df, and sensitivity to prior choice. Regulators expect CLSI-style ANOVA/REML estimates for claims; Bayesian is acceptable as a supportive or exploratory analysis, preferably with the frequentist result alongside.

Q9. How do multi-site / multi-instrument extensions change the model?

Add random effects for site (or instrument/lot) above day: reproducibility = within-lab + between-site. Few sites (3) means very few df for site variance, so the reproducibility CI is wide and CLSI-style designs ask for >= 3 sites/lots as a pragmatic compromise. Exact counts for EP05 Ed4: not verified.

Q10. A level has repeatability CV 2.2% and within-lab CV 2.5%. What do you conclude about the dominant source?

Repeatability contributes ~77% of total variance here (2.22/2.52 ~ 0.77): most imprecision is within-run noise, not day/run drift. Comparing variances, not CVs, makes the shares additive.
