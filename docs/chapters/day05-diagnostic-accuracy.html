Agreement with a non-reference comparator: why PPA ≠ sensitivity

Truth D is hidden. The comparator C itself errs (Se 0.85, Sp 0.99); the candidate T has true Se 0.92, Sp 0.96.

set.seed(53)
N <- 200000; D <- rbinom(N, 1, .30)
C <- rbinom(N, 1, ifelse(D == 1, .85, .01)); T <- rbinom(N, 1, ifelse(D == 1, .92, .04))
agr <- report_agreement(T == 1, C == 1)
true <- report_2x2(T == 1, D == 1)
# discrepant resolution: discordant pairs resolved by the truth, concordant pairs keep the comparator label
resolved <- ifelse(T != C, D, C)
dr <- report_2x2(T == 1, resolved == 1)
kable(data.frame(
  Estimate = c("True sensitivity (unknowable)", "True specificity (unknowable)",
               "PPA vs comparator", "NPA vs comparator",
               "'Sensitivity' after discrepant resolution", "'Specificity' after discrepant resolution"),
  Value = round(c(true$est[1:2], agr$est[1:2], dr$est[1:2]), 4)))
Estimate Value
True sensitivity (unknowable) 0.9204

PPA vs comparator 0.8958
NPA vs comparator 0.9062
‘Sensitivity’ after discrepant resolution 0.9312

  • PPA/NPA are not estimates of Se/Sp: the comparator’s errors enter. Here PPA (0.896) is below the true Se (0.920) because the comparator’s false positives sit in the denominator; NPA (0.906) is far below the true Sp (0.960) because the comparator’s false negatives make correct candidate positives count as disagreements. The direction depends on the comparator’s error pattern.
  • Discrepant resolution resolves only the disagreements, so errors made by both tests are never corrected. Here the “sensitivity” rises above the truth (0.931 vs 0.920) while the “specificity” is almost unchanged (0.960 vs 0.960): the bias is real but its size depends on the error structure. FDA 2007 says there is no statistical fix. [S/Y]

Verification bias and the Begg–Greenes correction

Only positives and 20% of negatives are sent to the reference.

set.seed(54)
N <- 5000; D <- rbinom(N, 1, .30); T <- rbinom(N, 1, ifelse(D == 1, .90, .15))
ver <- rbinom(N, 1, ifelse(T == 1, 1, 0.2))
naive_se <- sum(T == 1 & D == 1 & ver == 1) / sum(D == 1 & ver == 1)
naive_sp <- sum(T == 0 & D == 0 & ver == 1) / sum(D == 0 & ver == 1)
# Begg-Greenes: P(D|T) from verified, P(T) from everyone
pDpos <- mean(D[T == 1 & ver == 1]); pDneg <- mean(D[T == 0 & ver == 1]); pT <- mean(T)
bg_se <- pDpos * pT / (pDpos * pT + pDneg * (1 - pT))
bg_sp <- (1 - pDneg) * (1 - pT) / ((1 - pDneg) * (1 - pT) + (1 - pDpos) * pT)
kable(data.frame(estimate = c("Complete-data truth", "Naive (verified only)", "Begg-Greenes corrected"),
  Sensitivity = round(c(sum(T & D) / sum(D), naive_se, bg_se), 3),
  Specificity = round(c(sum(!T & !D) / sum(!D), naive_sp, bg_sp), 3)))
estimate Sensitivity Specificity
Complete-data truth 0.901 0.834
Naive (verified only) 0.979 0.508
Begg-Greenes corrected 0.907 0.835

Naive sensitivity is inflated, specificity deflated. Correction assumes verification depends only on the test result. [Y]

(d) Ten interview questions

show_questions(5, "../interview_questions.csv")

Q1. <98><85> Why does FDA’s 2007 statistical guidance say you may not call agreement with a non-reference comparator sensitivity and specificity?

“When a new test is evaluated by comparison to a non-reference standard, sensitivity and specificity are not appropriate terms to describe the comparative results” - the comparator’s own errors are folded in, so the numbers are percent agreement (PPA, NPA, OPA), and they are asymmetric (which test is the comparator matters). State the calculation explicitly.

Q2. What is discrepant resolution and why is it biased?

Only discordant results are re-tested with a better method. Cases where both tests are wrong are never examined, so the new test is credited with agreement it does not deserve and its apparent sensitivity/specificity is inflated. FDA 2007: there is no statistical solution; prospectively define the reference standard for all subjects.

Q3. Wilson versus Clopper-Pearson?

Clopper-Pearson (exact) guarantees at least nominal coverage but is conservative; Wilson has coverage closer to nominal and behaves well near 0 and 1 and with small n. Regulatory summaries often use either; state which. Neither is a good choice when assumptions of independence fail (clustered samples).

Q4. A test has Se 90% and Sp 85%. What is its PPV at 1% prevalence?

PPV = 0.90.01/(0.90.01+0.15*0.99) = 0.009/0.1575 = 5.7%. Sensitivity and specificity are properties of the test given the population spectrum; predictive values need the prevalence of the intended-use population.

Q5. How do you compare sensitivity of two tests run on the same subjects?

Restrict to the diseased subjects and use McNemar’s test on the discordant pairs (b vs c); same for specificity in the non-diseased. A confidence interval for the paired difference uses the same discordant counts. Unpaired two-proportion tests ignore the correlation and lose power.

Q6. <98><85> What is verification bias and how can you correct it?

If test-positives are more likely to get the reference standard than test-negatives, naive sensitivity rises and specificity falls. Begg-Greenes (inverse-probability style) correction uses P(D|T) in verified subjects and P(T) in all, valid if verification depends only on the test result (MAR). Better: design to verify a random sample of negatives.

Q7. <98><85> What if the reference standard is imperfect?

Sensitivity and specificity are biased (usually toward 0.5 if errors are independent of the test). Options: composite/expert-panel reference blinded to the index test (as in the pTau217 pivotal reader panel), latent class models, report as agreement. Document in the SAP.

Q8. What is the AUC and how do you get its CI and compare two AUCs?

AUC = P(case result > control result) (Mann-Whitney). DeLong’s method gives the variance from structural components, and for two correlated AUCs on the same subjects the covariance too. pROC::ci.auc and roc.test(method = “delong”, paired = TRUE).

Q9. Why a partial AUC?

Whole-curve AUC averages regions of no clinical relevance. When the test is used at high specificity (rule-in) or high sensitivity (rule-out), summarise only that range; standardise (McClish) to 0.5-1 to read like an AUC.

Q10. What are STARD 2015 and QUADAS-2 for?

STARD 2015 is a 30-item reporting checklist for diagnostic accuracy studies. QUADAS-2 assesses risk of bias and applicability (patient selection, index test, reference standard, flow and timing), used in systematic reviews and as a design checklist.
